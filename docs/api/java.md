# Java API

Package `frc.soar`, in `soarbridge.jar`. Robot code uses `SoarBridge`,
`SoarCommand`, `CommandListener` and `RobotActuators`. The other classes in
the package are generated by SWIG and are an implementation detail.

The native library loads automatically the first time the bridge is used:
from `java.library.path` if it is there, otherwise from inside the jar.

## `SoarBridge`

Implements `AutoCloseable` and owns all native memory. Call it from one thread
(the robot loop). The periodic methods never wait on Soar.

### Lifecycle

| Method | Description |
| --- | --- |
| `SoarBridge(String productionsPath)` | Default settings |
| `SoarBridge(String productionsPath, int decisionsPerInput, int debuggerPort)` | |
| `SoarBridge(String productionsPath, int decisionsPerInput, int debuggerPort, int realtimePriority)` | See [Configuration](configuration.md) |
| `void start()` | Starts the Soar thread and loads the productions (tens of ms). Call from `robotInit`. Throws `IllegalStateException` if loading fails |
| `boolean isRunning()` | |
| `void close()` | Stops Soar and frees native memory. Safe to call twice. Other methods throw `IllegalStateException` afterwards |

### Inputs by path

| Method | Description |
| --- | --- |
| `boolean setNumber(String path, double value)` | Float WME |
| `boolean setInt(String path, long value)` | Int WME |
| `boolean setString(String path, String value)` | String WME |
| `boolean setBool(String path, boolean value)` | The string `true` or `false` |
| `boolean removeInput(String path)` | Removes a value, or an identifier and everything under it |
| `void sendInputs()` | Publishes the values set since the last call |

Each setter returns `false` if the path is invalid or conflicts with an
existing one. See `lastWarning()`.

### Fixed-schema inputs

| Method | Paths |
| --- | --- |
| `setMatch(double timeRemainingSeconds, MatchMode mode, Alliance alliance)` | `^match.*` |
| `setDrive(double x, double y, double headingDegrees, double vx, double vy)` | `^drive.pose.*`, `^drive.velocity.*` |
| `setVision(boolean targetDetected, double distanceMeters, double yawDegrees)` | `^vision.*` |
| `setIntakeHasPiece(boolean hasPiece)` | `^intake.has-piece` |
| `setElevatorHeight(double heightMeters)` | `^elevator.height` |

Once any of these is called, `sendInputs()` writes the whole fixed schema.
Robots that never call them get none of it.

`MatchMode` has `Disabled`, `Autonomous`, `Teleop` and `Test`. `Alliance` has
`Red` and `Blue`.

### Commands

| Method | Description |
| --- | --- |
| `void onCommand(String name, CommandListener listener)` | Accepts commands named `name` and calls `listener` for each in `dispatchCommands`. Replaces an earlier listener. Throws `IllegalArgumentException` for an invalid name |
| `int dispatchCommands()` | Runs `onCommand` listeners for every new command |
| `int dispatchCommands(RobotActuators actuators)` | As above. Built-in commands with no listener go to `actuators` |

Both return the number of commands dispatched. A listener that throws marks its
command `^status error`. The remaining commands are still dispatched, then the
first exception is rethrown.

### Diagnostics

| Method | Description |
| --- | --- |
| `double meanLatencyMillis()` | Mean time from `sendInputs()` to commands ready |
| `double maxLatencyMillis()` | Worst time from `sendInputs()` to commands ready |
| `long inputsProcessed()` | Snapshots the agent has processed |
| `long inputErrors()` | Setter calls refused |
| `long commandsRejected()` | Unknown name, or missing or malformed parameter |
| `long commandsDropped()` | Discarded because nobody dispatched them |
| `long commandsUnhandled()` | Dispatched with no listener or actuator method |
| `long outputConstantsIgnored()` | Constants on the output-link |
| `String lastWarning()` | Most recent non-fatal problem, or `""` |

## `CommandListener`

```java
@FunctionalInterface
public interface CommandListener {
  void execute(SoarCommand command);
}
```

Runs on the thread that calls `dispatchCommands`. Throwing marks the command
`^status error`.

## `SoarCommand`

One command from the output-link.

| Method | Description |
| --- | --- |
| `String name()` | Output-link attribute, e.g. `ground-intake` |
| `long id()` | Identifies the command on the output-link |
| `Map<String, Object> params()` | Every parameter except `^status`, unmodifiable. Values are `Long`, `Double` or `String`. Nested identifiers use dotted keys |
| `boolean has(String key)` | |
| `double getDouble(String key)`, `getDouble(String key, double fallback)` | Int, float, or numeric string. Default fallback `0.0` |
| `String getString(String key)`, `getString(String key, String fallback)` | Any value as Soar prints it. Default fallback `""` |
| `boolean getBoolean(String key, boolean fallback)` | `true` / `false`, or `1` / `0` |

## `RobotActuators`

Handler interface for the built-in commands:

```java
public interface RobotActuators {
  void move(double vx, double vy, double omega);   // ^move: m/s, m/s, rad/s
  void turnTo(double headingDegrees);              // ^turn-to: absolute
  void setElevator(double heightMeters);           // ^set-elevator
  void runIntake(double speed);                    // ^run-intake: -1.0 to 1.0
  void shoot(boolean execute);                     // ^shoot
}
```
